## ทำอย่างไร — 4 ขั้นตอน

### 1. ดึงโค้ดล่าสุดจาก Course Repository

```bash
cd engse203-lab          # โฟลเดอร์ course repository ที่ clone ไว้ตั้งแต่ Week 01
git pull
```

ถ้ายังไม่เคย clone

```bash
git clone <URL ของ course repository>
cd engse203-lab
```

### 2. เข้าโฟลเดอร์ Pre-LAB

```bash
cd labs/week-05-react-mini-app/pre-lab05
```

โฟลเดอร์นี้มี

```text
pre-lab05/
├── README.md                    ← ไฟล์ที่คุณกำลังอ่านอยู่
├── PRE_LAB05A_GUIDE_TH.md       ← คู่มือรอบแรก
├── PRE_LAB05B_GUIDE_TH.md       ← คู่มือรอบสอง
├── PRELAB_NOTES_05A.md          ← ใบจดคำตอบรอบแรก
├── PRELAB_NOTES_05B.md          ← ใบจดคำตอบรอบสอง
└── starter/                     ← แอปตัวอย่างที่เขียนเสร็จแล้ว
```

### 3. ติดตั้งและรันแอปตัวอย่าง

```bash
node -v                # ต้องได้ v22.12.0 ขึ้นไป
cd starter
npm ci
npm run dev
```

เปิด URL ที่ขึ้นบนหน้าจอในเบราว์เซอร์ จะเห็นแอปชื่อ **Study Task Board**

> แอปนี้เป็นคนละโจทย์กับ Campus Service Request ที่จะทำใน LAB **ไม่ใช่เฉลย** แต่ใช้แนวคิดเดียวกัน

### 4. เปิดคู่มือของรอบนั้น แล้วทำตามทีละกิจกรรม

- ก่อนคาบ 5A → เปิด `PRE_LAB05A_GUIDE_TH.md`
- ก่อนคาบ 5B → เปิด `PRE_LAB05B_GUIDE_TH.md`

คัดลอกไฟล์ `PRELAB_NOTES_05A.md` ไปไว้ที่ไหนก็ได้ที่คุณสะดวก แล้วเติมคำตอบลงไป จะพิมพ์ออกมาเขียนมือก็ได้

## สิ่งที่ต้องเข้าใจก่อนเริ่ม

**Pre-LAB นี้ไม่ต้องใช้ความรู้ React มาก่อน** คุณจะเจอคำถามสองแบบ

| สัญลักษณ์ | ความหมาย |
|---|---|
| (ไม่มีสัญลักษณ์) | ตอบจากสิ่งที่เห็นบนจอ — ต้องตอบให้ครบ |
| ◆ | **ยังตอบไม่ได้ตอนนี้ก็ไม่เป็นไร** จดสิ่งที่เดาไว้ แล้วเราจะหาคำตอบด้วยกันในคาบ |

**อย่าไปหาคำตอบของข้อ ◆ จากอินเทอร์เน็ตหรือ AI มาแปะ** จุดประสงค์ของ Pre-LAB คือทำให้คุณ*เดินเข้าห้องเรียนพร้อมกับคำถามในหัว* ความสงสัยที่คุณมีคือสิ่งที่ทำให้บทเรียนในคาบมีความหมาย ถ้าเดินเข้ามาพร้อมคำตอบที่ลอกมา คุณจะเสียโอกาสนั้นไป

## เอามาด้วยในวันเรียน

ไม่ต้องส่งไฟล์ แต่**เอาใบจดคำตอบมาด้วย** (ไฟล์ในโน้ตบุ๊กหรือกระดาษก็ได้)

ต้นคาบจะมีแบบทดสอบสั้น ๆ ที่ถามเรื่องที่คุณเจอใน Pre-LAB — ไม่เก็บคะแนน แต่ผู้สอนใช้ผลนั้นตัดสินใจว่าจะจัดคู่และปรับวิธีสอนในวันนั้นอย่างไร

## ถ้ารันไม่ได้

**อย่าพยายามแก้ `package.json` เอง**

1. ตรวจว่า `node -v` ได้ v22.12.0 ขึ้นไปหรือไม่
2. ตรวจว่าอยู่ในโฟลเดอร์ `starter/` ที่มีไฟล์ `package.json` จริง
3. ถ้ายังไม่ได้ **บันทึกคำสั่งที่รันกับข้อความ error ทั้งหมด** แล้วนำมาถามในคาบ

การที่คุณรันไม่ได้เป็นข้อมูลที่ผู้สอนต้องรู้ ไม่ใช่ความผิดของคุณ — และถ้ามีหลายคนเจอปัญหาเดียวกัน เราจะได้แก้พร้อมกันตอนต้นคาบ
