# Pre-LAB 05 Starter — Study Task Board

แอปตัวอย่างที่**เขียนเสร็จแล้ว** ใช้สำหรับสังเกตในกิจกรรม Pre-LAB 05A และ 05B

**คุณไม่ต้องแก้โค้ดในโฟลเดอร์นี้** หน้าที่ของคุณคือเปิดดู กดเล่น และจดสิ่งที่เห็น

```bash
npm ci          # ติดตั้งครั้งแรก
npm run dev     # รันแล้วเปิด URL ที่ขึ้นบนหน้าจอ
```

ต้องใช้ Node.js v22.12.0 ขึ้นไป

## หมายเหตุ

โจทย์ในแอปนี้คือ **Study Task Board** ซึ่งเป็นคนละโจทย์กับ Campus Service Request ที่จะทำใน LAB 05 — จงใจให้ต่างกันเพื่อ**ไม่ให้เป็นเฉลย** แต่ใช้แนวคิดชุดเดียวกัน

ข้อมูลทั้งหมดเป็นข้อมูลสาธิต ห้ามใส่ข้อมูลจริงหรือข้อมูลส่วนบุคคล
