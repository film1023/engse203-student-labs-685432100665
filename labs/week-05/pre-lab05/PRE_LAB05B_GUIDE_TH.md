## 2. กิจกรรม A — ข้อมูลหน้าตาเป็นอย่างไร (6 นาที)

1. ในหน้า Dashboard กดปุ่มเปลี่ยน preference
2. ดูใน Local Storage หาคีย์ `engse203-prelab05-preference`
3. คลิกที่คีย์นั้นเพื่อดูค่าที่เก็บไว้

### คำถาม

**A1.** ค่าที่เห็นในช่อง Value มีเครื่องหมายอะไรครอบอยู่บ้าง (เช่น `{ }` `" "` `[ ]`)

_____________________________________________

**A2.** ค่านั้นเป็นตัวเลข ข้อความ หรือ object — ดูจากสีและเครื่องหมายที่ DevTools แสดง

_____________________________________________

**A3 ◆** ถ้าโปรแกรมอยากเก็บข้อมูลที่เป็น object เช่น `{ ชื่อ: "สมชาย", อายุ: 20 }` ลงในที่ที่เก็บได้แต่ข้อความ คุณคิดว่าต้องทำอย่างไร

_____________________________________________

| # | ทำอะไร | ผลที่เห็น |
|---|---|---|

_____________________________________________

## 4. กิจกรรม C — ลองทำข้อมูลให้พัง (7 นาที)

> **ปลอดภัย** — เราแก้เฉพาะข้อมูลของแอปฝึกหัดตัวนี้ ไม่กระทบอะไรในเครื่องคุณ

1. ใน DevTools → Local Storage ดับเบิลคลิกที่ **Value** ของคีย์ `engse203-prelab05-preference`
2. ลบค่าเดิมทิ้ง แล้วพิมพ์แทนด้วยข้อความมั่ว ๆ เช่น

```
{ นี่ไม่ใช่ข้อมูลที่ถูกต้อง
```

3. กด Enter แล้ว refresh หน้าเว็บ

### คำถาม

**C1.** หลัง refresh หน้าเว็บ **ขาวเปล่า** หรือ **ยังใช้งานได้ปกติ**

_____________________________________________

**C2.** เปิดแท็บ **Console** ใน DevTools มีข้อความ error สีแดงหรือไม่

_____________________________________________

**C3 ◆** ถ้าคุณเป็นผู้เขียนโปรแกรมนี้ คุณอยากให้แอปทำอย่างไรเมื่อเจอข้อมูลที่อ่านไม่ออก

_____________________________________________

**C4 ◆** ข้อมูลใน Local Storage ผู้ใช้แก้ได้เองง่าย ๆ อย่างที่คุณเพิ่งทำ — แล้วข้อมูลประเภทไหนที่ **ไม่ควร** เก็บไว้ตรงนี้

_____________________________________________
