## อ่านตรงนี้ก่อนเริ่ม

**Pre-LAB นี้ไม่ต้องใช้ความรู้ React มาก่อน และไม่ต้องเขียนโค้ดแม้แต่บรรทัดเดียว**

หน้าที่ของคุณคือ **เปิดแอปที่เขียนเสร็จแล้ว กดดู และจดสิ่งที่เห็น**

คำถามในเอกสารนี้มี 2 ชนิด สังเกตสัญลักษณ์ให้ดี

| สัญลักษณ์ | ความหมาย |
|---|---|
| (ไม่มีสัญลักษณ์) | **ตอบจากสิ่งที่เห็นบนจอ** — ต้องตอบให้ครบ |
| ◆ | **ยังตอบไม่ได้ตอนนี้ก็ไม่เป็นไร** — จดสิ่งที่คุณเดาไว้ แล้วเราจะหาคำตอบด้วยกันในคาบ |

> **อย่าไปค้นคำตอบของข้อ ◆ จากอินเทอร์เน็ตหรือ AI มาแปะ** เพราะจุดประสงค์ของ Pre-LAB คือให้คุณ *มีคำถามค้างอยู่ในหัว* ก่อนเข้าคาบ ความสงสัยที่คุณมีคือสิ่งที่ทำให้บทเรียนในคาบมีความหมาย ถ้าคุณเดินเข้ามาพร้อมคำตอบที่ลอกมา คุณจะเสียโอกาสนั้นไป

## 1. เตรียมเครื่องมือ (5 นาที)

ต้องมี Node.js เวอร์ชัน 22.12.0 ขึ้นไป ตรวจด้วย

```bash
node -v
```

เปิด terminal ในโฟลเดอร์ `pre-lab05/starter/` แล้วรัน

```bash
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดงในเบราว์เซอร์

**ถ้ารันไม่ได้:** บันทึกข้อความ error ไว้แล้วหยุดตรงนี้ อย่าพยายามแก้ `package.json` เอง นำ error มาถามในคาบ — การที่คุณรันไม่ได้เป็นข้อมูลที่ผู้สอนต้องรู้

## 2. กิจกรรม A — ทายก่อนกด (8 นาที)

เปิดแอปแล้ว **ทายก่อน** ว่าแต่ละ URL จะแสดงหน้าอะไร จากนั้นค่อยพิมพ์ URL นั้นดูจริง

การทายผิดไม่ใช่เรื่องเสียหาย — ที่สำคัญคือคุณได้คิดก่อนเห็นคำตอบ

| URL | ฉันทายว่าจะเห็น | สิ่งที่เห็นจริง |
|---|---|---|
| `#/` | | |
| `#/tasks/TASK-101` | | |
| `#/tasks/TASK-999` | | |
| `#/about` | | |
| `#/unknown` | | |

### คำถาม

**A1.** สองบรรทัดสุดท้าย (`#/tasks/TASK-999` และ `#/unknown`) หน้าจอที่เห็นเหมือนกันหรือต่างกัน

_____________________________________________

**A2.** ถ้าต่างกัน ต่างกันตรงไหน อธิบายจากสิ่งที่เห็น

_____________________________________________

**A3 ◆** ทำไมนักพัฒนาถึงตั้งใจให้สองกรณีนี้แสดงคนละแบบ ทั้งที่ผู้ใช้ก็ "หาไม่เจอ" เหมือนกัน

_____________________________________________

## 3. กิจกรรม B — เปิด DevTools ดูว่าอะไรถูกโหลด (7 นาที)

1. เปิด DevTools (กด `F12`)
2. ไปที่แท็บ **Network**
3. กดปุ่มเคลียร์รายการ (ไอคอนวงกลมมีเส้นขวาง)
4. กดลิงก์ในเมนูสลับหน้าไปมา **3 ครั้ง**
5. ดูรายการที่เกิดขึ้นใน Network

### คำถาม

**B1.** ตอนที่กดสลับหน้า มีไฟล์ `.html` ถูกโหลดใหม่หรือไม่

_____________________________________________

**B2.** ลองกด `F5` เพื่อ refresh แล้วดู Network อีกครั้ง — ต่างจากตอนกดลิงก์อย่างไร

_____________________________________________

**B3 ◆** ถ้าเว็บนี้มีแค่ไฟล์ `index.html` ไฟล์เดียว แล้วมันเปลี่ยนหน้าได้อย่างไร ลองเดา

_____________________________________________

## 4. กิจกรรม C — หาว่าอะไรอยู่ที่ไหน (5 นาที)

เปิดโฟลเดอร์ `src/` ใน VS Code แล้วค้นหาว่าข้อความต่อไปนี้อยู่ในไฟล์ไหน (ใช้ `Ctrl+Shift+F` ค้นทั้งโปรเจกต์ได้)

| ค้นหาคำว่า | อยู่ในไฟล์ |
|---|---|
| `HashRouter` | |
| `Route` | |
| `Outlet` | |
| `useParams` | |

### คำถาม

**C1.** ไฟล์ที่มีคำว่า `Route` อยู่ มีทั้งหมดกี่บรรทัดที่ขึ้นต้นด้วย `<Route`

_____________________________________________

**C2 ◆** `Outlet` อยู่ในไฟล์ที่ทำหน้าที่เป็น "กรอบ" ของทุกหน้า คุณคิดว่ามันทำหน้าที่อะไร

_____________________________________________

**C3 ◆** ในไฟล์ที่มี `<Route` ลองสังเกตค่าที่อยู่หลัง `path=` — มีเครื่องหมาย `#` อยู่ด้วยไหม แล้วทำไม URL บนเบราว์เซอร์ถึงมี `#`

_____________________________________________

## 5. กิจกรรม D — สังเกตว่าอะไรเปลี่ยนเมื่อไหร่ (5 นาที)

1. เปิดหน้า Task Detail (`#/tasks/TASK-101`) แล้ว **ดูข้อความบนแท็บของเบราว์เซอร์**
2. กดกลับไปหน้า Dashboard แล้วดูแท็บอีกครั้ง
3. กดปุ่มเปลี่ยน preference ในหน้า Dashboard แล้วสังเกตว่าอะไรเปลี่ยนบ้าง

### จัดประเภทสิ่งที่คุณเห็น

ลองจัดว่าแต่ละอย่างเกิดขึ้น "เมื่อไหร่"

| สิ่งที่เกิดขึ้น | เกิดตอนไหน (ตอบด้วยคำพูดของตัวเอง) |
|---|---|
| ข้อความบนแท็บเบราว์เซอร์เปลี่ยน | |
| ตัวเลขหรือข้อความบนหน้าจอเปลี่ยนหลังกดปุ่ม | |
| รายการ task ถูกกรองตามเงื่อนไข | |

**D1 ◆** ในสามอย่างข้างบน มีอันไหนที่ "ไม่ได้เกิดจากการกดปุ่ม" บ้าง

## 6. Exit Ticket — เติมใน `PRELAB_NOTES.md` (5 นาที)

ตอบสั้น ๆ ด้วยคำพูดของตัวเอง

1. URL หนึ่งอันที่คุณลอง และหน้าที่มันแสดง
2. ตอนกดสลับหน้า Network โหลดไฟล์ `.html` ใหม่หรือไม่
3. `#/tasks/TASK-999` กับ `#/unknown` แสดงเหมือนหรือต่างกัน
4. **คำถามที่คุณยังไม่เข้าใจ อย่างน้อย 1 ข้อ** ← ข้อนี้สำคัญที่สุด
