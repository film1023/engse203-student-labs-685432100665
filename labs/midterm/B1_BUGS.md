## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

## ตัวอย่างรูปแบบการเขียน

> ⚠️ นี่คือ **บั๊กสมมติเพื่อสอนวิธีเขียน** — **ไม่ใช่** บั๊กจริงในข้อสอบ

| อาการ | ไฟล์ : บรรทัด | สาเหตุ | แก้อย่างไร |
|---|---|---|---|
| กดปุ่มไม่ได้ แต่พอโหลดหน้าเสร็จฟังก์ชันทำงานเองทันที | `Foo.jsx : 12` | เขียน `onClick={handleClick()}` มีวงเล็บ → JavaScript **เรียกฟังก์ชันทันที**ตอน render แล้วเอาค่าที่ return มาเป็น handler | เอาวงเล็บออก เป็น `onClick={handleClick}` (ส่งตัวฟังก์ชัน ไม่ใช่ผลลัพธ์) |

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) ที่แผงสรุป | SummaryPanel.jsx : 12 | ในการวนลูป .map() เพื่อสร้างองค์ประกอบ React ลิสต์ ไม่ได้ใส่ key prop ให้กับ Element นอกสุด |เพิ่ม key={key} ที่แท็ก <article className="summary-card"> เพื่อให้ React ระบุแต่ละ Element ได้อย่างถูกต้อง |
| 2 | ตัวเลข "เสร็จสิ้น" ในแผงสรุปไม่ตรงกับที่เห็นจริง | DashboardPage.jsx : 50,51 | เช็คสถานะของ completed เป็น 'in-progress' ซ้ำกับของกำลังดำเนินการ และไม่ได้ใส่ [requests] ใน dependency array ของ | เปลี่ยนเงื่อนไขเช็คเป็น request.status === 'completed' และเติม [requests] ใน useMemo |
| 3 | กดตัวกรองสถานะใด ๆ แล้วผลไม่เปลี่ยน (เหมือนกรองไม่ทำงาน) | DashboardPage.jsx : 55 |ตอนส่งข้อมูลไปยัง RequestList ไปส่งตัวแปร requests (ข้อมูลดิบทั้งหมด) แทนที่จะส่ง filteredRequests (ข้อมูลที่ผ่านการกรองแล้ว) | เปลี่ยน prop จาก requests={requests} เป็น requests={filteredRequests} ในการ Render <RequestList /> |
| 4 | เปลี่ยน URL REQ-101 → REQ-102 แล้วข้อมูลไม่เปลี่ยน | RequestDetailPage.jsx : 28 | Dependency Array ของ useEffect เป็นอาร์เรย์ว่าง [] ทำให้ Hook ทำงานแค่ครั้งแรก และไม่ดึงข้อมูลใหม่เมื่อ Parameter ใน URL เปลี่ยนแปลง | ใส่ [requestId, reloadKey] เข้าไปใน Dependency Array เพื่อให้รัน useEffect ดึงข้อมูลใหม่ทุกครั้งที่ URL เปลี่ยน |
| 5 | กด "ลบ" แล้วการ์ดหาย แต่ตัวเลขในแผงสรุปไม่ลด | DashboardPage.jsx : 65 | ฟังก์ชัน handleDelete ไม่ได้สั่งอัปเดต state หลักอย่าง requests (ไปอัปเดต state ย่อยอื่น) ทำให้ SummaryPanel ยังอ้างอิงและคำนวณจากข้อมูลชุดเดิม | ปรับฟังก์ชัน handleDelete ให้เรียก setRequests(nextRequests) ด้วยข้อมูลชุดใหม่หลังทำการลบแล้ว |
| 6 | กด "ลบ" แล้วหน้าพัง/ว่างเปล่า | RequestCard.jsx : 16 | การกดปุ่มลบเกิด Event Bubbling ทะลุไปยัง Link นอกสุดการ์ด ทำให้ React Router พยายามพานิวิเกตเปลี่ยนหน้าขณะลบจนเกิด Error | เพิ่มฟังก์ชัน handler ที่ปุ่มลบแล้วเรียก e.stopPropagation() เพื่อยับยั้ง Event ทะลุไปยัง Container ด้านนอกก่อนทำการลบ |
